\# QuickBite - Campus Food Ordering App



QuickBite is a cross-platform mobile application prototype developed for a university activity.



The app allows students to browse food available at the campus canteen, add items to a cart, place an order, and track the order status.



\## Features



\- Splash screen

\- Login and guest access

\- Browse food items

\- Search menu items

\- Filter food by category

\- View food item details

\- Select item quantity

\- Add items to cart

\- Update and remove cart items

\- Automatic subtotal calculation

\- Checkout screen

\- Card and cash payment options

\- Order confirmation with generated order number

\- Order status tracking

\- User profile and order history

\- Responsive mobile interface



\## Technologies Used



\- React Native

\- Expo

\- JavaScript

\- React Navigation

\- Context API

\- Expo Vector Icons
